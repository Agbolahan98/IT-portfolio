# Agbolahan | IT Support Engineer — Interactive Portfolio

A responsive, static portfolio website with an iPhone-inspired lock screen, an IT-themed home screen, and clickable portfolio apps. It uses plain HTML, CSS and JavaScript—no build tools or paid hosting required.

## Before publishing

1. Open `index.html` and review the portfolio wording.
2. In `script.js`, open the `contact` section and replace `YOUR_EMAIL@example.com` with your professional email.
3. Replace the generic LinkedIn URL with your actual profile URL.
4. Review the experience and project descriptions. Add accurate employer names, dates, screenshots, and measurable results where you can.
5. If you have a CV PDF, add it to the project folder and create a Resume app/link before publishing.

## Preview locally

Double-click `index.html` to open it in a modern browser. For best testing, check both phone-sized and desktop-sized layouts.

## Publish free with GitHub Pages

1. Create or sign in to a GitHub account at https://github.com/.
2. Create a new public repository named `agbolahan-portfolio` (or another name you prefer).
3. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose the `main` branch and `/(root)` folder, then save.
7. Wait for GitHub Pages to publish. Your website will be available at a URL similar to `https://YOUR-USERNAME.github.io/agbolahan-portfolio/`.

GitHub's Pages instructions: https://docs.github.com/en/pages

## Structure

- `index.html` — page structure and portfolio content
- `styles.css` — visual design, responsive layout, and animations
- `script.js` — live clock, unlock/swipe interaction, and app navigation

## Notes

- Google Fonts are loaded online. The page still has system font fallbacks if those fonts cannot load.
- This is a static site; no backend or server configuration is required.
- Contact links are placeholders until you replace them with your real details.
